# CloudWatch Logs to Excel Exporter (RHEL 9.8 Edition)

CloudWatch Logs に出力されたログを収集し、フォント・レイアウト・配色を徹底的に磨き上げた美しい Excel ファイル (`.xlsx`) を出力する RHEL 9.8 向けのツールです。

---

## 🌟 主な特徴

1. **実行前の認証チェック (`aws login --remote`)**
   - 実行開始時に AWS CLI (`aws sts get-caller-identity`) で認証状態を検証します。
   - 未認証またはセッション期限切れの場合は、`aws login --remote` による認証を促す警告メッセージを表示して即座に終了します（終了コード: `1`）。

2. **操作権限チェック & スイッチバック機能**
   - CodeCommit 操作用の限定ロール等が適用されており CloudWatch Logs の操作権限がない場合を検知します。
   - **モード切替**:
     - **通常（デフォルト）**: スイッチバック用シェルのパスと手動実行コマンドを警告表示して終了します（終了コード: `2`）。
     - **自動（`--auto-switchback`）**: 指定されたスイッチバック用シェルをシェルスクリプト親プロセス内で自動的に `source` して環境変数を更新・反映し、再検証後に処理を自動続行します。
   - スイッチバック用シェルの配置場所は `--switchback-script <PATH>` オプションまたは環境変数 `AWS_SWITCHBACK_SCRIPT` で柔軟に指定可能です。

3. **CloudWatch Logs の全ログ取得 & ブロック表示**
   - 指定時間範囲内の全ロググループ（または指定プレフィックス/特定グループ）を抽出します。
   - **各ロググループごとに個別のシート**を作成します。
   - シート内では**ログストリームごとにスタイリッシュな見出し帯（ブロック）**で区切って表示します。

4. **キーワード強調表示（ハイライト機能）**
   - `--highlight` パラメータで指定した文言（例: `ERROR,WARN,Exception` 等、カンマ区切りで複数指定可能）をログ本文から検出。
   - 該当する行のメッセージやセルを優しいパステルレッドの背景（`#FEE2E2`）と深紅の太字（`#991B1B`）でハイライト表示します。

5. **極めて美しい Excel デザイン**
   - **フォント**: 全セルで可読性の高い `Meiryo UI` を統一採用。
   - **セル幅自動調整**: 半角・全角文字の視覚的幅を正確に計算し、最適な列幅を自動設定。
   - **メッセージ折り返し**: 長大なログや複数行ログ（スタックトレース等）も美しく読めるように `wrapText`（折り返し）と行の高さを自動調整。
   - **Summary（概要）シート**: 先頭にレポート全体のサマリーシートを自動生成（期間、ログ件数、ストリーム数、ハイライト件数、各シートへの参照一覧）。
   - **ウィンドウ枠固定 (Freeze Panes)**: スクロールしてもヘッダーが見失われないよう自動固定。

6. **RHEL 9.8 標準環境のみで動作（追加インストール不要）**
   - `openpyxl` や `pandas` 等のサードパーティライブラリは**一切不要**です。
   - Python 標準ライブラリ（`zipfile`, `xml`, `re`, `json` 等）のみで OpenXML 規格に完全準拠した XLSX ファイルを直接生成するため、クリーンな RHEL 9.8 環境でそのまま動作します。

## 🚀 使い方

### 1. 基本実行（直近 1 時間のログを出力）
```bash
./cw_logs_exporter.sh
```

### 2. 時間範囲を指定して実行
```bash
./cw_logs_exporter.sh \
  --start-time "2026-10-04 00:00:00" \
  --end-time "2026-10-04 06:00:00"
```
※ 日時は `"YYYY-MM-DD HH:MM:SS"` (JST) のほか、`"1h"` (1時間前), `"24h"` (24時間前) などの相対指定も可能です。

### 3. キーワードを強調（ハイライト）表示
```bash
./cw_logs_exporter.sh \
  --start-time "2026-10-04 00:00:00" \
  --end-time "2026-10-04 06:00:00" \
  --highlight "ERROR,WARN,FATAL,Exception,Timeout"
```

### 4. 自動スイッチバックの有効化とシェルパス指定
```bash
./cw_logs_exporter.sh \
  --auto-switchback \
  --switchback-script "/path/to/team/switchback.sh" \
  --start-time "24h" \
  --highlight "ERROR,FATAL" \
  --output "cw_report_24h.xlsx"
```
- `--auto-switchback` (`-a`) を指定すると、現在のロールで権限が不足している場合に指定されたシェルを自動で `source` してロールを切り替え、処理を続行します。
- 指定しない場合は、スイッチバックが必要である旨の案内メッセージを出力して終了します。

### 5. ロググループのプレフィックス指定（絞り込み）
```bash
./cw_logs_exporter.sh \
  --log-group-prefix "/aws/lambda/" \
  --start-time "1h" \
  --highlight "ERROR"
```

## ⚙️ コマンドライン引数一覧

| オプション | 短縮 | デフォルト値 | 説明 |
| :--- | :---: | :---: | :--- |
| `--start-time <TIME>` | `-b` | 終了の1時間前 | ログ取得開始日時 (`"YYYY-MM-DD HH:MM:SS"`, `"1h"`, `"24h"` 等) |
| `--end-time <TIME>` | `-e` | 現在時刻 | ログ取得終了日時 (`"YYYY-MM-DD HH:MM:SS"`) |
| `--output <FILE>` | `-o` | `./cloudwatch_logs_YYYYMMDD_HHMMSS.xlsx` | 出力先 Excel ファイルパス (`.xlsx`) |
| `--highlight <WORDS>` | `-H` | なし | 強調表示する文言（カンマ区切りで複数指定可能） |
| `--log-group-prefix <PRE>` | `-p` | なし | 対象ロググループのプレフィックス (例: `/aws/ecs/`) |
| `--log-groups <NAMES>` | `-g` | なし | 対象ロググループ名をカンマ区切りで指定 |
| `--auto-switchback` | `-a` | `false` | 権限不足時に自動でスイッチバック用シェルを source して続行 |
| `--switchback-script <PATH>` | `-s` | `./switchback.sh` | スイッチバック用シェルの配置パス (環境変数 `AWS_SWITCHBACK_SCRIPT` も可) |
| `--region <REGION>` | `-r` | AWS CLI 設定 | 対象 AWS リージョン (例: `ap-northeast-1`) |
| `--profile <PROFILE>` | - | AWS CLI 設定 | 使用する AWS CLI プロファイル名 |
| `--mock-data <JSON>` | - | なし | テスト用モック JSON データパス (AWS API 呼び出しを行わない) |
| `--help` | `-h` | - | ヘルプメッセージを表示 |

## 🎨 Excel 出力デザイン仕様

| 項目 | デザイン仕様 |
| :--- | :--- |
| **全体フォント** | `Meiryo UI`（文字サイズ: 通常 9.5pt、見出し 10〜14pt） |
| **Summary 表見出し** | ディープインディゴ背景（`#3730A3`）＋ 白太字 |
| **ログ一覧表見出し** | ディープネイビー背景（`#1E3A8A`）＋ 白太字 |
| **ストリーム見出し帯** | スレートブルー背景（`#334155`）＋ 白太字 |
| **ゼブラストライプ** | 偶数行にごく薄いクールグレー（`#F8FAFC`）を適用し視認性向上 |
| **罫線 (Border)** | 繊細な薄いグレー（`#CBD5E1`）で統一 |
| **ハイライト行/セル** | パステルソフトレッド背景（`#FEE2E2`）＋ 深紅太字（`#991B1B`） |
| **列幅自動調整** | 半角・全角文字の幅を計算し最適な余白を確保 |
| **折り返し (WrapText)** | ログ本文列（メッセージ列）は自動折り返し＋適切な行高調整 |
| **ウィンドウ枠固定** | ヘッダー行を固定表示（スクロールしても見出しが常に見える状態） |

## 🧪 テスト・検証

付属のテストスイートで、すべての認証・権限・スイッチバック分岐および Excel 生成をテストできます。

```bash
# 全自動テストの実行 (6シナリオ)
bash tests/run_tests.sh
```

テストシナリオ：
1. **未認証検知**: トークン期限切れ・未ログイン時に `aws login --remote` を促して終了（終了コード `1`）。
2. **権限不足検知**: `--auto-switchback` なしの状態でスイッチバック用シェルを案内して終了（終了コード `2`）。
3. **自動スイッチバック成功**: `--auto-switchback` ありでシェルを `source` し、環境更新後に正常完了（終了コード `0`）。
4. **スイッチバック用シェル不在検知**: 指定パスにシェルが存在しない場合にエラー終了（終了コード `3`）。
5. **スイッチバック後も権限不足**: スイッチバック実行後も権限が不足している場合にエラー終了（終了コード `4`）。
6. **エンドツーエンド生成**: モックデータによる Excel 生成およびスタイル・レイアウトの検証。
